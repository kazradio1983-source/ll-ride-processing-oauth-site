Privacy Policy

Last updated: October 2, 2026

LL Ride Processing is a personal automation used by its owner for cycling activity processing.

The app accesses Google Drive only when authorized by the account owner. It uses authorized Drive files and file metadata only to process Ride source files and save derived processing results for that same owner.

Google user data is not sold or used for advertising.

The account owner controls the source files and generated files in Google Drive and can revoke Google OAuth access at any time.
